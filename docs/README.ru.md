# HPC Workspace — установка для студента

Панель объединяет tmux, ваши задания Slurm и агентов Codex. У каждого студента своя установка, настройки и авторизация.

## Быстрый старт

Нужны Linux с Python 3.10+, SSH и пользовательским systemd на компьютере; Node.js 18.19+, tmux и Slurm на кластере. Codex нужен для вкладки агентов. Проверенная версия CLI — 0.154.0.

1. Создайте SSH-алиас на **конкретный login-узел** с вашим именем пользователя: [пример](../examples/ssh-config).
2. Подключитесь `ssh my-hpc hostname` и проверьте ключ сервера. Для автоматического соединения нужен SSH-ключ или доступный SSH agent.
3. На **своём компьютере** выполните:

```bash
git clone https://github.com/Vor-Art/HPC-Workspace.git
cd HPC-Workspace
./install.sh --host my-hpc
~/.local/bin/hpc-workspace open
```

Серверный порт выбирается автоматически. В браузере панель будет на `http://127.0.0.1:8765`. Если локальный порт занят, добавьте `--local-port 8767` к установке.

Для профиля **YOLO / Fast / Extra High**:

```bash
./install.sh --host my-hpc --server-config examples/server.yolo.json
```

В обычной установке используются настройки самого Codex. Каждый студент входит в свой аккаунт отдельно; [инструкция по установке и входу](installation.md#3-enable-codex-agents). Глобальный `~/.codex/config.toml` установщик сохраняет как есть.

## Использование

- **Обновить** запрашивает свежие данные сразу.
- **Агенты**: новый диалог, вопросы, остановка и открытие того же диалога в tmux.
- **Основные / Архив**: скрыть сессию и вернуть для продолжения. История и работа сохраняются.
- **Терминалы**: создать сессию, читать вывод, отправлять команды и клавиши.
- **Ресурсы**: ваши задания, выделенные ресурсы, очередь, время и отмена выбранного задания.

Для терминального агента на сервере используется `hpc-codex`, либо `hpc-workspace-server codex`, если первая команда уже была занята.

Служба туннеля стартует при входе в Ubuntu и переподключается после восстановления сети. VPN подключается обычным способом. Статус и журнал:

```bash
systemctl --user status hpc-workspace-tunnel
journalctl --user -u hpc-workspace-tunnel -n 30 --no-pager
```

Свои подтверждённые квоты можно записать в `~/.config/hpc-workspace/server.json` на сервере. Чужие лимиты в проект не зашиты. Примеры и описание полей — в [настройках](configuration.md).

Панель служит для управления; вычислительные нагрузки запускаются внутри Slurm-выделений согласно правилам вашего кластера.

## Обновление

```bash
git pull --ff-only
./install.sh --host my-hpc
```

Повторите свой `--local-port`, если использовали нестандартный. Полное описание установки, удаления и диагностики — в [installation.md](installation.md).
